Development release built from current `main`. All of the following are new since 0.7.0 and
are **not independently reviewed**.

- **Pairing protocol v9.** Both phones must run 0.15.0; older versions are refused with an
  upgrade message. Pair every chat again on 0.15.0: new features only apply to chats paired
  with this version.
- **Bigger pads.** 1–64 MiB, default 16 MiB. Pads are streamed straight into separate
  encrypted storage, with one key per slot that is erased on use. Both phones contribute
  randomness to every pad.
- **Local wipe, wipe all and recovery.** Done chats can be removed from the list.
- **Peer wipe** (app menu, *unreviewed*, off by default): wiping a chat also asks the friend's
  phone to remove its copy. Both phones need it switched on.
- **Strict chats** (chosen at pairing):
  - opening one needs the server, through a 60-second signed unlock;
  - it locks when you leave the app;
  - it's lost for good if the phone misses its 12 h / 3 day / 14 day check-in, or if it's wiped.
  - Needs the updated relay.
- **Backup relays:** up to two per chat (conversation menu → Backup relays).
- **Group chats** (app menu → Groups): each message goes separately to every member using that
  friend's own pad.
- **USB pairing:** fixes for packet-boundary hangs and stuck accessory negotiation, plus a step
  log with **Copy USB details**.
- **Relay:** strict-chat shares and unlock authority, journaled storage, Node 26 base image.

## Install

Download `otp-pager-0.15.0.apk` below and install it on **both** phones. It's signed with the
owner's release key; `SHA256SUMS` lists its hash.

- **Coming from 0.7.0 or any CI debug build:** Android won't install a differently signed APK
  over it. Uninstall the old app first. That deletes its chats and pads, which is intended:
  never restore an old pad.
- **On both phones:** pair each friend again in person on 0.15.0.

## Server / Portainer

Redeploy the relay **before** pairing strict chats:
- repository `https://github.com/masadams/otp-pager`, reference `refs/heads/main`;
- compose path `deploy/portainer-stack.yml`;
- image `ghcr.io/masadams/otp-pager-relay:0.15.0` (`relay-image.txt` gives the exact digest).

Keep the existing stack name, relay token, named data volume and proxy network. Pull and
redeploy with image re-pull enabled.

The volume now also holds `journal.log` and `authority-key.pem`. Back up the whole volume, and
never copy `authority-key.pem` to another relay. Normal chats keep working on the old relay;
strict chats and the new unlock endpoints need this one.

## What to test

See `docs/USB_PAIRING.md`, `docs/TWO_DEVICE_TEST.md` and `docs/REVIEW_PACKAGE.md`:
- USB pairing in both directions at 16 and 64 MiB. If it fails, use **Copy USB details** on both
  phones.
- A message and a reply, then a restart.
- Peer wipe with the setting on both phones.
- Lock, unlock and expiry of a strict chat.
- A backup relay while the main one is down.
- A three-person group.
