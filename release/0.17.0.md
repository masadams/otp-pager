Development release built from current `main`. Changes since 0.16.0 are **not independently
reviewed**.

- **Post-quantum USB pairing (pairing protocol v10).** The cable channel that carries the pad now
  uses ECDH plus ML-KEM-768 (FIPS 203). Recorded pairing traffic stays safe unless both are
  broken. The comparison code covers every new key. **Both phones need 0.17 to pair or renew;**
  existing chats keep working.
- **Post-quantum relay TLS.** Relay connections offer the hybrid `X25519MLKEM768` key exchange
  on every Android version, using a bundled Conscrypt. Certificate checks are unchanged. Your
  proxy has to support it too (see Server below).
- **Test server connection** (friend details) and **Test server** (setup). These check the
  address, the secure connection, post-quantum TLS, relay health and this chat's access. A
  failure says what to fix. Read-only.
- **Strict chats, from a security review:**
  - strict text is never written to the ordinary draft store;
  - an unlock reply that arrives after you've left the app can't cache the key share;
  - an open chat clears the moment its lease ends;
  - a chat is only wiped on a **signed** retirement answer from the server. A missing share
    means "unavailable", and nothing is deleted;
  - retired shares are removed from the relay's live files and can't be re-enrolled;
  - unlock replay protection no longer evicts live entries.
- **App lock:** Groups and the pairing screens also ask for the unlock after the grace period.
- **Groups:** honest delivery status, unsent text is kept, and "Retry for …" sends only to the
  members who missed it.
- **Message order:** messages carry the sender's time and a sequence number inside the encrypted
  payload, so a late delivery appears where it was written.

## Install

Download `otp-pager-0.17.0.apk` below and install it over 0.15.0 or 0.16.0 on **both** phones.
It's signed with the same release key, so it updates in place and keeps chats, pads and
pairings. `SHA256SUMS` lists its hash. The APK is about 12 MB larger than before, from Bouncy
Castle and Conscrypt.

## Server / Portainer

Redeploy the relay: keep the stack name, token, volume and network, remove any `RELAY_IMAGE`
override, then **Pull and redeploy** with re-pull on. The pinned default is the 0.17.0 relay
(`ghcr.io/masadams/otp-pager-relay:0.17.0`). The new relay adds strict-share tombstones and
signed retirement answers.

Nginx Proxy Manager: optional `ssl_ecdh_curve X25519MLKEM768:X25519:prime256v1;` in the proxy
host's Advanced tab, **only** if NPM's `openssl version` is 3.5 or newer. Step-by-step
instructions are in `docs/DEPLOYMENT.md`.

## What to test

- **Connection:** Friend details → Test server connection shows ✓ on every line (or "!" on
  post-quantum TLS before the proxy change).
- **Pairing:** a new USB pairing and a renewal between two 0.17 phones.
- **Strict chat:** lock on leaving the app; a lapse past the deadline gets removed (needs the
  new relay).
- **Groups:** a send with one member unreachable shows the right status and Retry.
- **Order:** send while the other phone is offline, reply, then deliver. Order follows writing
  time.
