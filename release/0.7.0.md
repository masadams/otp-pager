First integrated Android field release, with a Docker/Portainer relay for self-hosting.

- Up to 12 separate two-device chats, each with its own pad, device identity and encrypted vault.
- Automatic USB pairing; QR/file fallback; setup navigation hidden after complete pairing.
- Monochrome layout for regular Android and Mudita Kompakt-sized displays.
- Connection, unread, queued and receipt indicators; recovery retries the exact ciphertext.
- Cross-chat pairing-material reuse guards and documented security review.

## Install

Download `otp-pager-0.7.0-debug.apk` below and install the SAME APK on both devices.
These are the exact APK bytes from successful build 39984156312, not a fresh signing key.
The release is debug-signed; stable owner-controlled signing is still unfinished.
If replacing an older debug build requires uninstalling, pair both devices again with
fresh pad/secret material. Never restore an operational pad after uninstalling.

Open the chat picker → New chat, name your friend, then pair the two physical devices.
At least one needs server settings saved. After successful pairing, server, pad and
identity controls are available through Chat settings. Sync runs while the app is open.

## Server / Portainer

Use repository `https://github.com/masadams/otp-pager`, reference `refs/heads/main`,
compose path `deploy/portainer-stack.yml`, image `ghcr.io/masadams/otp-pager-relay:0.7.0`.
Keep the existing stack name, relay token, named data volume and proxy network.
Pull/redeploy with image re-pull enabled. Nginx upstream remains `otp-pager-relay:8080`.
`relay-image.txt` supplies the immutable digest for an exact pin.
See docs/DEPLOYMENT.md for full configuration. Publishing this release does not
itself update a private server; that requires access to its Portainer/SSH deployment.

## Verification and limits

The tested source was merged into main with its full history. 16 JVM tests, 26 Android
12/API 31 tests at 480×800 resolution (including the keyboard), and 9 Node relay tests
pass. Android 10/API 29 and Android 15/API 35 pass 25 tests each, with the API-31-only
compact test intentionally skipped. Lint, APK assembly, Docker persistence smoke tests,
and multi-architecture relay publication pass. Actual Kompakt USB/firmware behavior,
e-ink refresh and battery still need physical validation.

This is an experimental, unaudited prerelease. SecureRandom pads, HMAC and device
signatures do not establish information-theoretic OTP security. Remaining limitations
include shared relay tokens, retained pad bytes, rollback/cloning, trusted plaintext
USB provisioning and unfinished release signing. Read SECURITY_REVIEW.md before use.
