Development release built from current `main`. Changes since 0.15.0 are **not independently
reviewed**.

- **One unlock to get in.** The app asks for your screen lock once when you open it. It stays
  unlocked while you move between its own screens, the QR scanner or a quick file picker, and
  locks again after 60 seconds out of sight or when Android restarts it. The unlock prompt opens
  by itself instead of behind an extra button. Strict chats still lock when you leave the app.
- **Refreshed look.** Rounded buttons, fields and cards, a clean sans-serif font, touch feedback,
  bold names in Chats, and message bubbles aligned by sender (yours solid black on the right).
  Still black on white for e-ink; codes stay monospace.
- **NFC + Wi-Fi pairing paused.** Pair nearby, Renew nearby, Tap + Wi-Fi and Tap setup · NFC
  show "Coming soon". Pair and renew by USB cable. See `docs/NFC_WIFI_HANDOFF.md` for why.

## Install

Download `otp-pager-0.16.0.apk` below and install it over 0.15.0 on **both** phones. It's
signed with the same release key as 0.15.0, so it updates in place: chats, pads and pairings are
kept, and nothing needs pairing again. `SHA256SUMS` lists its hash.

- **Coming from 0.7.0 or a CI debug build:** uninstall the old app first and pair again, as
  described in the 0.15.0 notes.

## Server / Portainer

No relay changes. Keep running the 0.15.0 relay; `ghcr.io/masadams/otp-pager-relay:0.16.0`
is the same service rebuilt from this commit.

## What to test

- Open the app: exactly one screen-lock prompt. Open USB pairing, Groups or settings and come
  back: no second prompt. Leave the app for over a minute: it asks again.
- Cancel the unlock prompt: the lock screen stays, with an Unlock button to retry.
- The new screens on each phone, including e-ink if you use one.
- The NFC options are greyed out and say "Coming soon"; USB pairing and renewal still work.
- A message and a reply after updating, to confirm chats survived the update.
