Development release built from current `main`. Changes since 0.17.0 are **not independently
reviewed**.

- **Stronger pad randomness (pairing protocol v11).** Each phone generates the full pad on its
  own, and the pad is the XOR of both streams. It is at least as unpredictable as the better of
  the two phones' generators, and no short seed is stretched. Every byte passes continuous
  health tests (stuck, biased or repeating output stops the pairing). You can also tap
  **Add microphone noise** on the USB screen: about 1.5 s of raw audio is health-tested,
  hashed with SHA3-512 and mixed into that phone's seed. It is never stored or sent. It adds
  to the generator and never replaces it. A phone's generator is still a cryptographic
  generator, not a certified true-random source.
- **One-time MAC.** New pairings authenticate each message with Poly1305 under that slot's
  single-use key (information-theoretic, like the pad itself) instead of HMAC-SHA256.
  Existing chats keep HMAC until you renew or re-pair.
- **Both phones need 0.18 to pair or renew.** Existing chats keep working without re-pairing.
- **Secure deletion:**
  - **Keep messages** (friend details): 1 hour, 6 hours, 24 hours (default) or **until
    read**, on this phone only;
  - **Delete message history now**, and long-press any message to delete just that one;
  - every expiry or deletion re-encrypts the chat's vault under a new Keystore key and
    destroys the old one, so leftover copies on flash can't be decrypted;
  - **Emergency wipe (hold)** in the ⋮ menu on the chat list wipes every chat after a 3-second press, with
    no typing.
  - Your friend's phone keeps its own copy under its own setting.

## Install

Download `otp-pager-0.18.0.apk` below and install it over 0.17.0 on **both** phones. It's
signed with the same release key, so it updates in place and keeps chats, pads and pairings.
`SHA256SUMS` lists its hash. The app asks for microphone access only if you tap **Add
microphone noise**.

## Server / Portainer

No relay changes. The 0.17.0 relay stays pinned, so you don't need to redeploy. Nginx Proxy
Manager needs no changes either.

## What to test

- **Pairing:** a new USB pairing between two 0.18 phones, with and without microphone noise.
  Both phones show "Mixing message keys from both phones" reaching 100 %.
- **Messages:** send and receive on the new pairing, and on an existing chat.
- **Retention:** set "until read". A read message disappears about a minute later.
- **Delete:** long-press a delivered message, then use Delete message history now.
- **Emergency wipe:** releasing before 3 s cancels it.
