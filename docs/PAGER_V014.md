# v0.14: chats first

The app opens a full Chats screen instead of a station dashboard. A conversation has a back button, friend's name, a single short connection line, messages and Send. There are no normal Pad/Device tabs, manual Sync button, byte counter or administration strip. Draft saved and a near-limit warning appear only when useful. Delivery and time sit below the message. The existing launcher component is retained so installed shortcuts keep working.

Add friend asks for a name and guides physical pairing. The first unused default profile is reused instead of leaving an empty Chat 1 behind. Previously saved server setup is copied to a new friend as before, without copying keys or identity. If neither station is set up, one enters its server address/token; the other can choose Get setup from my friend and proceed to USB or experimental NFC/Wi-Fi without inventing credentials. Pairing still requires both devices to compare full codes. A partial/legacy pairing routes to the existing explicit recovery/manual tools rather than silently replacing material.

Friend details holds renewal, renaming, receiving options and the entry to Advanced setup. Advanced retains all existing server, pad, identity, QR/file, revocation and recovery tools. The USB wizard now puts short instructions and comparison first, with technical/security detail behind About USB pairing. Background receiving remains opt-in and has the same battery and physical Kompakt validation limits.

Chats shows unread/draft/waiting states without message-content previews. While open it checks one friend per foreground cycle and refreshes the active engine snapshot afterward; it never marks inbox messages read. Background checks remain bounded to three friends. A navigation request made during a check is retained for completion rather than silently ignored. Existing drafts remain attached to the original chat. Private fields and list content are cleared on leaving; Android credential/screenshot/overlay protections remain in force. A damaged active vault produces a persistent recovery card and does not reset keys, pad counters or storage.

Pairing cryptography, OTP allocation, signatures, wire messages and relay behavior are unchanged. This UI does not establish an independent cryptographic audit or hardware compatibility. The signed update check uses actual v0.13 source; no server redeploy is required. New native journeys exercise first launch, profile reuse, guided server setup, no-server reader choice, USB wizard entry, existing friends/drafts, advanced navigation and non-destructive vault recovery at the compact 480×800 viewport and regular phone sizes.
